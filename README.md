# Día a Día — Descargas

Aplicación de escritorio para Windows 11 y Ubuntu.

Los instaladores y las actualizaciones se publican en [Releases](https://github.com/Manolo580/daiil/releases). Este repositorio contiene únicamente las distribuciones y la información de descarga.

El diario, los apuntes y los archivos personales se guardan en cada computador.
